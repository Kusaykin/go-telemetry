# cmd/agent

В данной директории будет содержаться код Агента, который скомпилируется в бинарное приложение.

## Параметры

Переменная окружения приоритетнее флага, флаг — значения по умолчанию.

| Флаг | Переменная | По умолчанию | Описание |
|------|------------|--------------|----------|
| `-a` | `ADDRESS` | `localhost:8080` | адрес эндпоинта HTTP-сервера, куда отправляются метрики |
| `-r` | `REPORT_INTERVAL` | `10` | частота отправки метрик на сервер в секундах |
| `-p` | `POLL_INTERVAL` | `2` | частота опроса метрик из runtime в секундах |
| `-k` | `KEY` | пусто | ключ подписи; пусто — запросы не подписываются |
| `-l` | `RATE_LIMIT` | `1` | максимальное число одновременных запросов к серверу (целое от 1 до 1024) |

Если ключ задан, агент считает HMAC-SHA256 от несжатого JSON-тела запроса и передаёт hex-строку в заголовке `HashSHA256`.

Пустая переменная окружения игнорируется — используется значение флага. Интервалы задаются целым числом секунд больше нуля без единиц измерения (`10`, а не `10s`). Некорректное значение флага или переменной завершает запуск с ошибкой и выводом справки (`-h`).
