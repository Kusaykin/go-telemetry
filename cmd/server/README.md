# cmd/server

В данной директории будет содержаться код Сервера, который скомпилируется в бинарное приложение.

## Параметры

Переменная окружения приоритетнее флага, флаг — значения по умолчанию.

| Флаг | Переменная | По умолчанию | Описание |
|------|------------|--------------|----------|
| `-a` | `ADDRESS` | `localhost:8080` | адрес эндпоинта HTTP-сервера |
| `-i` | `STORE_INTERVAL` | `300` | интервал сохранения метрик на диск в секундах; `0` — запись после каждого обновления |
| `-f` | `FILE_STORAGE_PATH` | `metrics-db.json` | путь до файла с метриками; пустое значение флага (`-f=`) отключает работу с файлом |
| `-r` | `RESTORE` | `false` | загружать сохранённые метрики при старте |

`RESTORE` по умолчанию выключен, чтобы запуск без параметров не подтягивал данные прошлых прогонов.

Пустая переменная окружения игнорируется — используется значение флага. Интервал задаётся целым числом секунд без единиц измерения (`10`, а не `10s`). Некорректное значение флага или переменной завершает запуск с ошибкой и выводом справки (`-h`).
